Récap pour le lancement de MSL en développement 
    (un terminal pour chaque commande)

Lancement de la base de données:
    Ouvrir Docker Desktop

    Dans le dossier MSL_Backend:
        docker compose up 

Lancement du serveur Symfony
    Dans le dossier MSL_Backend:
        symfony serve --no-tls

Lancement de l'écouteur Stripe:
    Dans le dossier MSL_Backend:
        stripe listen --forward-to localhost:8000/api/stripe/webhook

Lancement du service Mail :
    Dans le dossier MSL_Backend (avec Limitation à un email) :
        php bin/console messenger:consume async --limit=1  -vv      

Lancement du serveur React front end:
    Dans le dossier MSL_Frontend_Dev:
        npm run dev
